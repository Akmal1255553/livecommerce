# LiveCommerce — engineering portfolio overview

**Repository:** [LiveCommerce](https://github.com/Akmal1255553/livecommerce)  
**Web demo:** https://livecommerce-web.onrender.com/#/home

LiveCommerce is an early-stage social commerce application for Central Asia. It explores short-form product discovery, live-shopping, merchant workflows and in-app checkout. The project is a product prototype, **not a claim of paying customers or production-scale traffic**.

## What this project demonstrates

- **Backend:** Laravel REST API design, modular services, authentication and PostgreSQL-backed data.
- **Video workflows:** Presigned uploads, object storage and video-processing orchestration.
- **Client applications:** Flutter mobile client and web/admin interfaces.
- **Local development:** Docker Compose-based development environment and supporting services.
- **Engineering practices:** Architecture documentation, automated tests and integration boundaries.
